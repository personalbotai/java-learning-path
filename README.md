## 📚 Curriculum Overview

1. **Java Foundations** — JVM vs JRE vs JDK, `main` entrypoint, primitive types, operators, naming conventions.
2. **Control Flow** — `if`/`else`, `switch` expressions, `for`, `while`, `do-while`, break & continue.
3. **Object-Oriented Programming** — Classes, objects, constructors, encapsulation, `this` keyword.
4. **Inheritance & Polymorphism** — `extends`, `super`, method overriding, abstract classes, runtime polymorphism.
5. **Interfaces & Contracts** — Interface definitions, default/static methods, multiple interface inheritance.
6. **Collections Framework** — `List` (`ArrayList`, `LinkedList`), `Set` (`HashSet`, `TreeSet`), `Map` (`HashMap`, `TreeMap`).
7. **Generics & Type Safety** — Generic classes & methods, wildcards (`? extends`, `? super`), type erasure.
8. **Exception Handling** — Checked vs unchecked exceptions, `try-with-resources`, custom exceptions.
9. **Lambdas & Streams API** — Functional interfaces, lambda expressions, `Stream` pipelines (`map`, `filter`, `reduce`, `collect`).
10. **Modern Java Features** — Records, Pattern Matching, Sealed Classes, Text Blocks, Virtual Threads overview.

## 🛠️ Local Development

Clone and run locally using any static web server:

```bash
git clone https://github.com/personalbotai/java-learning-path.git
cd java-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
